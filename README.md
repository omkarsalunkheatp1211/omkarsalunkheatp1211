# 💫 About Me:
I am a Full-Stack Developer with experience building backend services and modern web applications. My primary focus is on backend development using Spring Boot, where I design REST APIs, build scalable application logic, and work with relational databases. Alongside backend development, I develop responsive and user-friendly interfaces using React and TypeScript to deliver complete end-to-end solutions.

At TechnoNexis, I contribute to enterprise web applications by working across both backend and frontend development. I build REST APIs, work with microservice-based applications, and contribute to improving system performance through asynchronous communication using Kafka and efficient caching with Redis. I also develop React-based interfaces that integrate seamlessly with backend services.

Outside of work, I enjoy building practical software projects that solve real-world problems. I am currently developing **Linux Control Center**, an open-source platform designed to evolve from a command-line utility into a centralized Spring Boot and React web application capable of monitoring and managing hundreds of Linux machines from a single dashboard.

I enjoy writing clean, maintainable code, learning new technologies, and continuously improving my software engineering and problem-solving skills.
